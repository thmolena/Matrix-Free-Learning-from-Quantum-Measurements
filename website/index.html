The CPTP-Compiler-PINN framework makes physicality an architectural invariant in place of a penalty term: the density map is Hermitian, positive semidefinite, and unit-trace by construction, and a matrix-free compiler evaluates the Markovian (GKSL) generator while bypassing the dense Liouvillian. This page is the operational endpoint of that framework: it serves trained-model predictions from the Flask API in src/server.py for controlled, coordinate-level inspection.

Background & method

Why physicality should be enforced by construction, not by penalty.

Open quantum dynamics demand that one object stay physical at all times: the density matrix, which must lie in throughout relaxation, dephasing, leakage, crosstalk, and control-induced dissipation. For Markovian, time-local dynamics, the generator of this evolution takes the GKSL form:

A direct neural map is free to leave the manifold of Hermitian, positive semidefinite, unit-trace operators, and a negative-eigenvalue penalty merely asks the optimizer to repair an invalid output after the fact. This framework instead renders invalid states unrepresentable: a Cholesky density network parameterizes directly in , while the learned generator is held in CPTP form through and . A matrix-free compiler then lowers the open-system intermediate representation to a dense or structured Lindblad residual, evaluating the dynamics while bypassing the Liouvillian.

The local API exposes a trained model as an evaluation service: given coordinates and optional times , it returns wavefunction components and density values for inspection.

Interface notes

Each API response returns the wavefunction components, real and imaginary, together with the probability density.

The output panel renders one line per queried coordinate pair, so predictions can be inspected and checked by hand.

This interface is intended for local development; when the API is unavailable, it reports the connection state and withholds results.

conda activate qaoa

# 1. Train a model

# 2. Start the API

Candid framing. On complete single-qubit data, a classical least-squares fit endowed with the exact model is the strongest method (rates to ≈2%), and this framework cedes that regime openly. The CPTP-PINN is most useful under scarcity — guaranteed physicality (0.000 positivity violations) and trajectory error one to two orders of magnitude lower under sparse measurements, holding up at 10% observation. The two-qubit learned generator transfers to held-out states at 0.97 ± 0.005. Fast qutrit reconstruction remains the principal open problem, reported as such: a single-seed Fourier advantage dissolves under seed averaging. Full tables appear on the main project page.

Conclusion

Where this local demonstration sits within the full research account.

This interactive form is the operational endpoint of the pipeline: train a structure-preserving model, serve it locally, and inspect its predictions at chosen coordinates. The central claim is that physicality belongs in the architecture rather than in a penalty, and the analysis shows this discipline preserves what matters. Universal approximation continues to hold, the learned generator stays CPTP, the residuals supply an a-posteriori trace-norm certificate, and structured compilation sidesteps the dense Liouvillian altogether.

The study is deliberately reproducible and deliberately small: synthetic CPU simulations, the Markovian assumption, and five seeds. It stands as a controlled proof of concept, separate from hardware data or a state-of-the-art claim. The contribution is the modeling discipline behind the returned values rather than the interface that displays them.
